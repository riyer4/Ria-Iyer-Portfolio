# Ria Iyer — Portfolio

A retro pixel/arcade-themed portfolio site for Ria Iyer (Game Designer / HCI Researcher / UI-UX Designer).

Static HTML/CSS/JS, no build step — just open `index.html` or deploy the folder as-is (e.g. GitHub Pages).

## Structure
- `index.html` — home / start screen
- `about.html` — bio + skills
- `projects.html` — level-select grid linking to `projects/*.html` (15 game/UI/coding project pages)
- `archive.html` — bonus gallery of earlier design work (vector art, photography, music)
- `resume.html` — embedded resume + download link
- `contact.html` — contact form + direct links
- `assets/css/style.css`, `assets/js/main.js` — shared theme + interactions

Note: most project/art images are currently hotlinked from the previous Weebly site
(`iyerriaportfolio3.weebly.com`) rather than stored locally — swap in local copies under
`assets/img/` whenever convenient.
